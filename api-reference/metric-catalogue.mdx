---

Metric keys accepted by the `metrics` parameter of [`GET /v1/catchment-metrics`](/api-reference/catchments/get-catchment-metrics) and [`GET /v1/hex-metrics`](/api-reference/cells/get-hex-metrics). The list matches `GET /v1/metrics`.

| Column | Meaning |
| --- | --- |
| Unit | `Count`, `£`, `%`, `Index` or `Rank` |
| Combined as | How cell values are combined into a catchment value: a total, or an average with the weighting shown. Does not apply to single cells. |
| Projected | Whether the value changes with `projection_year` |
| Coverage | Nations with data. Outside them the value is usually `null` and should not be relied on. |
| Source | Origin of the data. `Derived` values are calculated from other metrics. |

## Not yet in catchment results
