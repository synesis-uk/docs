This reference lists the 114 metrics in the current full-access catalogue. [`GET /v1/metrics`](/api-reference/metrics/list-metrics) is the discovery contract for the caller's own organisation; its result can be smaller because access is checked per metric.

A postcode request accepts `Catchment` and `Authority` keys together. A cell request accepts only `Cell` keys. The direct authority endpoint accepts only `Authority` keys.

"Projected" means the metric depends on supported population projection inputs. With a valid `projection_year`, supported inputs are projected and dependent metrics are recalculated. Missing required projection inputs can make a value unavailable; optional multipliers can leave some source counts unchanged. Authority figures and current supply are not projected.

Nation scope follows the catalogue metadata and is not a guarantee that every location has data. A missing value is `null`. Source data can describe different periods; use `period_basis` from the catalogue and per-value details from the response.

## Care metric definitions

| Keys | Definition |
| --- | --- |
| `carehome_demand` | Estimated care-home demand from older age-band populations, not a measured waiting list. The omitted-year default uses source population. |
| `existing_beds_all`, `existing_beds_ensuite`, `existing_beds_wetroom` | Published beds in open non-specialist homes in the catchment. |
| `undersupply_existing_all`, `undersupply_existing_ensuite`, `undersupply_existing_wetroom` | Demand minus the matching existing supply. Negative is surplus. The categories overlap, are not additive, and exclude pipeline beds. |
| `planned_permitted_beds`, `planned_undecided_beds` | Separate care-bed totals in the published permitted and undecided planning pipeline. |
| `planned_permitted_count`, `planned_undecided_count` | Counts of projects in those pipeline categories. |
| `avg_fee_residential_week`, `avg_fee_nursing_week` | Unweighted means of usable weekly private-pay quoted fees, separate by care type. |
| `bed_weighted_avg_fee_residential_week`, `bed_weighted_avg_fee_nursing_week` | Means weighted by each contributing home's total beds. |
| `median_fee_residential_week`, `median_fee_nursing_week` | Medians of usable weekly private-pay quoted fees, separate by care type. |
| `fee_residential_count`, `fee_nursing_count` | Homes contributing usable fee data. |
| `fee_residential_beds_covered`, `fee_nursing_beds_covered` | Total beds at the homes contributing fee data. |

Residential fee statistics require at least five homes and 150 covered beds. Nursing fee statistics require at least three homes and 100 covered beds. Below-threshold fees are unavailable, while the sample counts remain reportable. Five years of historical private fees is not available.

## Authority metric definitions

| Keys | Definition |
| --- | --- |
| `la_avg_fee_residential_week`, `la_avg_fee_nursing_week` | Latest usable authority fee by financial year and care type. Each value has its own period, reporting authority and source metadata where available. |
| `la_occupancy_pct` | Combined general/dementia residential and nursing occupancy, excluding specialist/other beds. |
| `la_residential_occupancy_pct`, `la_nursing_occupancy_pct` | Separate older-adult occupancy categories. Each uses the latest published month for its category and requires that authority's reading for that month. |

These figures describe the reporting authority, not a radius or individual home. Missing English occupancy and non-English occupancy remain unavailable; no comparison-area value is substituted.
