# Catchment API documentation

Developer documentation for the Catchment API, built with [Mintlify](https://mintlify.com).

## Local preview

```bash
npm install
npm run dev
```

The preview runs at `http://localhost:3000`.

## Checks

```bash
npm run validate
npm run check:links
```

## Publishing

Mintlify deploys every push to `main`. Keep draft work on a branch until it is ready to publish.

See `AGENTS.md` for content and style rules.
